# Ponsaranya R — Portfolio

A modern AI/ML portfolio built with Next.js and ready for Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Add your resume

Place your PDF at:

`public/resume.pdf`

## Deploy to Vercel

1. Create a GitHub repository named `portfolio`.
2. Upload/push this project.
3. Sign in to Vercel with GitHub.
4. Import the `portfolio` repository.
5. Click Deploy.

Update the project GitHub links and descriptions in `app/page.tsx` whenever your repositories are ready.
